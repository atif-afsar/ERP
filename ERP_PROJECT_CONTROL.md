# EduNexus ERP Development Control

## Project Goal

Convert existing ERP into production-ready multi-tenant SaaS ERP.

---

# Current Architecture

Frontend:
- React
- TypeScript
- Vite
- Tailwind

Backend:
- Node.js
- Express
- TypeScript

Database:
- PostgreSQL

Deployment:
- Hostinger VPS

---

# Development Rules

1. Do not create duplicate features.
2. Analyze existing code before modification.
3. Database changes require migration files.
4. Complete one module before moving ahead.
5. Do not break existing APIs.
6. Every feature requires:
   - Database
   - Backend API
   - Frontend UI
   - Validation
   - Testing
