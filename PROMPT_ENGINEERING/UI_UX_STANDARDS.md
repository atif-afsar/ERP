# UI/UX STANDARDS
## Design System
- **Framework:** Tailwind CSS + Framer Motion.
- **Layout:** AppShell with side navigation and top-bar tenant switcher.

## Mode Adaptation (The "Switch")
- **School Mode:**
  - Labels: "Class", "Section", "Annual Fee", "Report Card".
  - Color Palette: Traditional Academic Blue/White.
- **Coaching Mode:**
  - Labels: "Batch", "DPP", "Mock Test", "Rank Ledger".
  - Color Palette: Energetic Orange/Dark Mode.

## Performance Targets
- **Initial Load:** < 2 seconds.
- **API Latency:** < 300ms for read operations.
- **Responsiveness:** Fully mobile-responsive for Parent/Student portals.
